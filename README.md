# UPI-Chunk

UPI-Chunk is a web application designed to help users plan large UPI payments by dividing a larger amount into multiple smaller transactions and tracking them as a single intended payment.

## Features

* Split a large amount into multiple smaller transactions
* Keep each individual transaction within a user-defined limit
* Track the cumulative amount
* Display the remaining amount after each transaction
* Simple HTML, CSS and JavaScript interface
* Client-side calculation with no backend required

## Example

If the intended payment is **₹5,000**, UPI-Chunk can divide it into smaller transactions such as:

```text
₹1,900
₹1,600
₹1,500
------
₹5,000
```

The application helps visualize the individual transactions while keeping track of the total.

## Tech Stack

* HTML
* CSS
* JavaScript

## Disclaimer

UPI-Chunk is a transaction-planning and calculation tool. Users should follow the applicable UPI, bank, payment-provider, and tax/compliance rules. Transaction limits and charges can vary by provider and may change over time.
